# Texture layout: per-tile PNGs under res/textures/, stitched at startup.
#
#   res/textures/blocks/<name>.png   16x16 block tiles (slot order = TILES
#   order in AtlasStitcher, NOT filename order — names carry no numbers so
#   faces can point at names independently)
#   res/textures/items/               (empty — arrives with inventory/drops, P3)
#
# Atlas = 256x256, 16-across, rows as needed (uv() maps slots to rects).
# To add art: drop the PNG, append its path to AtlasStitcher.TILES, point a
# block at the new slot (by name via slot(), never by magic index).
# AtlasTest fails the build on: missing/unsized PNGs, block pointing outside
# the manifest, unknown slot() names.
#
#   res/textures/blocks/tinted/     grayscale tintables for the biome-tint
#   pass (NOT stitched yet): re-drop leaves_oak.png, leaves_oak_opaque.png,
#   tallgrass.png, grass_side_overlay.png here when you have them (they were
#   here before and got deleted by mistake — sorry). See TODO "Biome tint".
#
